# 📧 Outlook Teams Notification Bot

Бот для автоматического мониторинга корпоративной почты Outlook (Shared Mailboxes), фильтрации тикетов ServiceNow (INC, RITM, SLA) и алертов мониторинга (SolarWinds, Zabbix) с последующей отправкой уведомлений в Microsoft Teams.

## 🚀 Основные возможности

- **Мониторинг в реальном времени**: Проверка входящих писем каждые 60 секунд.
- **Умная фильтрация**: 
  - Разделение по тегам стран: `[UZ]`, `[KZ]`, `[KG]`.
  - **SLA Alert Detection**: Продвинутое распознавание уведомлений об истечении SLA (по символу `%` и ключевым словам `violation`, `reached`).
- **Надежный парсинг (BeautifulSoup)**: Извлечение текста из писем любой сложности (без использования хрупких регулярных выражений).
- **Middle East Routing**: Автоматическая пересылка тикетов ОАЭ, Катара, Саудовской Аравии, Кувейта, Омана и Иордании в отдельный канал.
- **Масштабируемый кеш**: Увеличенный размер кеша (1000 записей) предотвращает повторные уведомления по старым тикетам.
  - Автоматический пропуск системного «мусора» (Zabbix, Work Orders, SCTASK).
  - Игнорирование отмененных пользователем задач (**Withdrawn**) и уведомлений о закрытии.
- **Weekend Silence**: Бот не будет тегать (упоминать) сотрудников в выходные дни, чтобы не беспокоить их в нерабочее время.
- **Напоминание о Time**: Автоматическая отправка напоминаний о заполнении Time по пятницам (утром в 11:00 и повторно после обеда в 15:00 по Бишкеку).
- **Вечернее пожелание**: Каждый будний день (Пн-Пт) в 18:00 по Бишкеку в тот же чат, куда приходят напоминания про Time, отправляется короткое сообщение с благодарностью за работу и пожеланием хорошего вечера.
- **Еженедельный отчет**: Автоматический сбор данных и отправка сводки по новым сотрудникам (NPR) и увольнениям (ER) каждую пятницу в **18:00 по времени Астаны**.
- **Динамическая конфигурация**: Список ответственных загружается из `data/responsibles.json` на лету, не требуя перезапуска бота.
- **Автоматический деплой (CI/CD)**: Настроен пайплайн через GitHub Actions — любые изменения в коде сами улетают на сервер.
- **Docker-контейнеризация**: Полная изоляция, надежное атомарное сохранение состояния в `data/` и простой запуск одной командой.

## 🛠 Установка и настройка

### Переменные окружения (.env)
Создайте файл `.env` в корне проекта:
```env
CLIENT_ID=ваш_azure_client_id
CLIENT_SECRET=ваш_azure_client_secret
TENANT_ID=ваш_azure_tenant_id
TARGET_EMAIL=shared_mailbox@company.com
TEAMS_WEBHOOK_URL=https://outlook.office.com/webhook/...
TEAMS_REPORT_WEBHOOK_URL=https://outlook.office.com/webhook/... (опционально для отчетов)
```

### Запуск через Docker (рекомендуется)
```bash
docker-compose up --build -d
```
Стейт бота (JSON отчеты, чекпоинты и токен авторизации) будут безопасно храниться в примонтированной папке `data/`.

### Локальный запуск
1. Установите зависимости: `pip install -r requirements.txt`
2. Запустите бота: `python -m bot.main`
3. При первом запуске перейдите по ссылке в консоли для авторизации через Microsoft Graph API.

### Тесты
```bash
pip install -r requirements-dev.txt
pytest tests/ -v
```

## 🤖 Структура проекта
- `bot/` — исходный код пакета бота (config, parser, reports, storage, teams, main).
- `data/` — директория для хранения токенов (`o365_token.txt`), отчетов и списков ответственных (`responsibles.json`).

## 🤖 CI/CD Пайплайн
Бот настроен на автоматическое обновление сервера при каждом `git push` в ветку `main`. 
Требуемые секреты в GitHub: `SSH_HOST`, `SSH_USER`, `SSH_PRIVATE_KEY`.
